# bank-bff

Каркас BFF «Понятных финансов». В текущем `main` нет `go.mod`, REST/SSE-обработчиков и их тестов. Их реализация остаётся в задачах сервиса; FIN-238 не добавляет бизнес-функциональность.

## Покрытие трёх наборов (FIN-238)

Для будущего сервиса подготовлены отдельные команды `make cover-unit`, `make cover-integration`, `make cover-api` и общая `make cover`. Сбор — Go `-json -race -count=1 -timeout=8m -coverpkg=./...`; профили `unit.out`, `integration.out`, `api.out` инструментируют один и тот же весь модуль, включая generated production-код и обычные `.go` тестовые helpers, без исключений. `TestUnit…` — изолированные функции без БД/сети, `TestIntegration…` — реальные зависимости/transport-клиенты/фоновые задания, `TestAPI…` — полная сборка BFF через HTTP/REST/SSE. Прямой вызов handler не является API-тестом. `make test-names` использует `go test -race -list` и отвергает тесты без одного из трёх префиксов, чтобы они не выпали из прогонов. Каждый `collect-*` сначала требует эту проверку, включая прямой локальный запуск.

Каждый набор требует **80% statements всего модуля** независимо. Проверяет закреплённый `go-test-coverage v2.20.1`; владелец принял его округление 79,95% до проходных 80,0%. Проценты не складываются: `make cover-combined` использует встроенное объединение трёх профилей и показывает дополнительный результат. Прежний информационный расчёт строк FIN-210 удалён; новая метрика с ним напрямую не сравнивается.

`scripts/check-suite.sh` проверяет через jq хотя бы один реально прошедший Test и отсутствие пропущенных/упавших тестов. Пакеты без собственных тестов допустимы и остаются в знаменателе. Отсутствующий, пустой, header-only или нулевой профиль отвергается до анализа покрытия. PostgreSQL недоступен — `CI=true` запрещает считать skip успешным результатом. Обвязка не вычисляет проценты и не объединяет профили.

CI сохраняет обязательный check `go`: без Go-модуля/набора или при недостаточном покрытии он падает. Это невыполненный критерий, а не 100% пустого каркаса. Сводка различает unit/integration/API/combined; профиль, JSON-лог и штатные отчёты сохраняются в artifact `coverage`, ссылка есть в сводке запуска. Нет прав записи в PR, в том числе для fork. Полнота бизнес-сценариев оценивается отдельно от процента.

Для запуска нужны Go, Bash, jq и Python 3.11+. Проверки guard и принятого округления: `python3 -m unittest discover -s scripts -p 'test_*.py'` с ограничением времени процесса.
